# e4 — contributors

The `/e4:*` command namespace is the persistent-memory tooling for this project.
The namespace itself is the signature: when you type `/e4:` you know whose system you're using.

If you extend or fix these commands, **sign your work** — add a line below.

| Handle | Name | Role | Since |
|--------|------|------|-------|
| e4 | Omar Araby | Creator / maintainer | 2026-06 |

## Commands in this namespace
- `/e4:init` — scaffold `.ai-memory/` + CLAUDE.md for a project
- `/e4:resume` — re-read memory and post a Resume Summary
- `/e4:new-task` — create a tracked task file
- `/e4:end-session` — persist the session to memory (the workhorse)

1. Add a row to the table above with your handle, name, role, and the month you joined.
